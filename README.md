# 🌐 Nexus

> 🎉 **We're Live!** Huge congratulations on the launch of **Nexus**! Explore the live site at **[IIVShar.github.io/Nexus]**.

**Nexus** is a private, all-in-one web search and productivity hub built for seamless research—with **zero account required**. It brings together traditional and voice-activated search, an integrated AI assistant, and essential everyday tools inside a fast, customizable interface.

---

## ✨ Key Features

* **🔍 Smart & Voice Search:** Browse the web, images, news, videos, and maps via text or voice commands, complete with search filters and an *"I'm Feeling Lucky"* option.
* **🤖 Nexus Chat:** An integrated conversational AI assistant ready to help with brainstorming, study tips, creative writing, and everyday queries.
* **🧰 Built-in Live Tools:** Instant access to a Calculator, 7-Day Weather forecasts, Translator, Dictionary, and Maps without leaving your session.
* **🖼️ In-App Media & Web Frame:** View high-resolution images, stream public domain videos, and open external links inside a full-screen web frame with built-in tab management.
* **🔒 Privacy-First & Customizable:** Engineered for private sessions with zero sign-ups needed, featuring seamless **Dark** and **Light** mode themes.

## 🛠️ Usage

1. Visit **[IIVShar.github.io/Nexus]**.
2. Type a query into the search bar, click the **microphone icon** to use voice search, or open **Nexus Chat**.
3. Switch between **Live Nexus Tools** (Weather, Calculator, Translator, Dictionary) or manage multiple pages using the **Tabs** bar.
4. Toggle between **Dark** and **Light** mode anytime to suit your workspace.
